# CryptoSafe Manager

CryptoSafe Manager - настольный менеджер паролей и секретов с локальным зашифрованным хранилищем, аудитом действий, защищенным буфером обмена, импортом/экспортом и дополнительным слоем security hardening.

## Обзор проекта и цель

Цель проекта - собрать локальное desktop-приложение, в котором чувствительная логика вынесена в отдельные модули:

- шифрование хранилища и управление ключами
- аутентификация и автоблокировка
- защищенный буфер обмена
- аудит действий и проверка целостности
- импорт, экспорт и обмен записями
- платформенные меры защиты

Проект ориентирован на модульную архитектуру: GUI, core-логика и база данных разделены, чтобы функциональность можно было расширять без полной переработки приложения.

## Основные функции

- хранение записей: логин, пароль, URL, заметки, теги, категория
- мастер-пароль и разблокировка хранилища при запуске
- шифрование записей через AES-GCM
- вывод ключей через Argon2id и PBKDF2-HMAC-SHA256
- защищенный буфер обмена с таймером очистки и whitelist
- журнал аудита с проверкой целостности
- импорт и экспорт данных
- QR-обмен и обмен зашифрованными записями
- panic mode, авто-блокировка, трей, профили безопасности


## Настройка проекта

### Требования

- Python 3.12+
- Windows для сборки дистрибутива через PyInstaller

### Установка зависимостей

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### Запуск приложения из исходного кода

```powershell
venv\Scripts\python.exe run.py
```

При первом запуске откроется мастер первоначальной настройки: выбор пути к базе данных и создание мастер-пароля.

### Запуск тестов

```powershell
venv\Scripts\python.exe -m pytest
venv\Scripts\python.exe tests\report\generate_summary.py
```

Покрытие считается через `pytest-cov`. Целевое значение - не менее 80%.

## Сборка Windows-дистрибутива

Для сборки одного исполняемого приложения в папке дистрибутива:

```powershell
powershell -ExecutionPolicy Bypass -File .\build_windows.ps1
```

Результат сборки:

- исполняемый файл: `dist\CryptoSafeManager\CryptoSafeManager.exe`
- зависимости рядом: `dist\CryptoSafeManager\_internal\`

Подробности по упаковке: [docs/WINDOWS_DISTRIBUTION.md](docs/WINDOWS_DISTRIBUTION.md).

## Как использовать основные функции

Подробное руководство находится в [docs/user_guide.md](docs/user_guide.md). Основные сценарии:

1. Создать хранилище и мастер-пароль при первом запуске.
2. Разблокировать vault и добавить записи.
3. Копировать пароли и коды через защищенный буфер обмена.
4. Импортировать или экспортировать данные.
5. Проверять события безопасности в журнале аудита.
6. Использовать QR-обмен для публичных ключей и записей.

## Известные ограничения

- GUI построен на Tkinter, поэтому визуальное поведение отличается между Windows, macOS и Linux.
- Часть платформенных защит зависит от наличия нативных API конкретной ОС.
- Функции, связанные с камерой и QR-сканированием, зависят от окружения рабочего стола.
- В рабочем дереве могут появляться локальные runtime-файлы вроде `src/app.db` и `src/config.json`; их не нужно включать в коммиты.
- Скриншоты не обновляются автоматически и должны пересниматься после заметных изменений интерфейса.
