# Руководство пользователя

## Установка и запуск приложения

### Запуск из исходного кода

1. Установите Python 3.12 или новее.
2. Создайте и активируйте виртуальное окружение.
3. Установите зависимости из `requirements.txt`.
4. Запустите приложение через `run.py`.

Пример:

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
venv\Scripts\python.exe run.py
```

### Запуск собранной Windows-версии

1. Соберите приложение через `build_windows.ps1` или используйте уже готовую папку `dist`.
2. Запустите `dist\CryptoSafeManager\CryptoSafeManager.exe`.

Все зависимости лежат рядом с исполняемым файлом в каталоге дистрибутива.

## Создание мастер-пароля и хранилища

При первом запуске откроется мастер настройки. В нем нужно:

- выбрать путь к базе данных vault
- задать мастер-пароль

После подтверждения приложение:

1. создаст SQLite-базу
2. инициализирует мастер-пароль
3. создаст базовые настройки безопасности
4. переведет приложение в обычный режим входа для следующих запусков

Рекомендации:

- используйте длинный уникальный мастер-пароль
- не повторяйте его с другими сервисами
- храните свои процедуры восстановления отдельно от приложения

## Добавление, редактирование и удаление записей

### Добавление записи

1. Разблокируйте vault.
2. Откройте действие добавления записи.
3. Заполните поля: название, логин, пароль, URL, заметки, категория, теги.
4. Сохраните запись.

Перед записью в базу данные записи шифруются.

### Редактирование записи

1. Выберите запись в списке.
2. Откройте редактирование.
3. Измените нужные поля.
4. Сохраните изменения.

После сохранения приложение повторно шифрует payload и обновляет журнал аудита.

### Удаление записи

1. Выберите запись.
2. Нажмите удаление.
3. Подтвердите действие.

В зависимости от версии схемы и текущей логики может использоваться мягкое удаление или физическое удаление записи.

## Использование защищенного буфера обмена

Защищенный буфер обмена нужен для копирования чувствительных данных на ограниченное время.

Что умеет эта функция:

- копирование паролей
- копирование TOTP-кодов
- автоматическая очистка по таймеру
- whitelist разрешенных приложений
- реакция на подозрительную активность
- очистка буфера при блокировке vault и panic mode

Типичный сценарий:

1. Выберите запись.
2. Скопируйте пароль или код.
3. Вставьте его в целевое приложение.
4. Дождитесь автоочистки или очистите буфер вручную.

Важно:

- если vault заблокирован, копирование блокируется
- при подозрительной активности буфер может быть очищен немедленно
- если включены уведомления, приложение показывает статус копирования и очистки

## Импорт и экспорт данных

Приложение поддерживает перенос и выгрузку данных.

### Импорт

Используйте импорт, когда переносите данные из другого менеджера или из ранее сохраненного файла.

Типовой порядок:

1. Откройте окно импорта/экспорта.
2. Выберите формат источника.
3. Укажите файл.
4. Проверьте параметры импорта.
5. Запустите импорт.

История операции записывается в `import_export_history`.

### Экспорт

Используйте экспорт, когда нужно создать переносимую копию записей.

Типовой порядок:

1. Откройте экспорт.
2. Выберите формат и объем данных.
3. Подтвердите путь сохранения.
4. Выполните экспорт.

Если включены функции обмена, можно использовать и QR/ключевой обмен для передачи записей.

## Дополнительные функции безопасности

### Автоблокировка

Vault может блокироваться:

- по таймеру неактивности
- при потере фокуса
- при ручной блокировке

Поведение зависит от настроек безопасности и особенностей платформы.

### Panic Mode

Panic mode предназначен для аварийного сокрытия данных. В зависимости от конфигурации он может:

- заблокировать vault
- очистить буфер обмена
- очистить чувствительные данные из памяти
- закрыть окна приложения

### Журнал аудита

Журнал аудита фиксирует важные действия и события безопасности. Его можно открыть из интерфейса приложения для последующей проверки.
